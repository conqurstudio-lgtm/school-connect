# White Premium App Theme Logic v1

## Product feeling

School Connect should feel like a premium school-life app, not a dashboard. The interface must stay quiet so each school's identity can come through through its logo, photos, teachers, children and posts.

## Color logic

- Main background is white: `#FFFFFF`.
- Main text is charcoal: `#262626`, not pure black.
- Secondary text is calm grey: `#5F6268`.
- Muted text is soft grey: `#9A9CA3`.
- Borders are barely visible: `rgba(0,0,0,0.06)`.
- Soft surfaces are used sparingly: `#F8F8F9` and `#FBFBFC`.
- Primary action is charcoal: `#2B2B2F`.

## Minimal layout logic

- A page should have one clear purpose and one clear next action.
- Remove explanation when the action already explains itself.
- Prefer white space over divider lines.
- Use borders only when separation is needed.
- Use fewer cards. Group related details naturally.
- Avoid heavy icon boxes. Use line icons as quiet helpers.

## Page behaviour logic

- Sign in should only ask for email and password.
- Sign up should feel like small steps, not a long form.
- School admin owns the structure: profile, classes, teachers and settings.
- Teacher owns the class space: class life, children, messages and reports.
- Parent sees School Life, messages and child reports.
- Parent claiming should be instant from a class link: find child, enter parent details, enter School Life.

## Children and parent claiming logic

- Teacher adds children first.
- Teacher shares a class link in the class WhatsApp group.
- Parent claims their child from that class.
- Parent enters name and phone.
- Parent immediately sees past and future School Life posts for that class.
- Teacher can later tap a child or parent to view claim/contact details.
