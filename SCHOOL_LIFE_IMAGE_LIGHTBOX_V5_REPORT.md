# School Life Image Lightbox v5

## Applied changes

- Added click-to-open image viewer to School Life ActivityCard
- Kept current image layout and edge-scroll behaviour

## Behaviour

- Clicking a School Life image opens it in a full-screen viewer.
- Tap outside the image or tap the close button to close.
- Existing image position and edge-scroll behaviour remain.
- Single-image and multi-image posts both support opening images.

## Admin Life recommendation

- Admin should see light engagement signals later: reaction count, comment/question count, and report flags.
- Admin should not become a public social feed manager.
- Parent private messages/questions should stay private unless they are school-level moderation issues.
