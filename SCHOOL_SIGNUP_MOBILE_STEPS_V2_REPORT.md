# School Signup Mobile Steps v2

## Applied changes

- Replaced the signup page with a mobile-first multi-step card flow.
- Kept public signup as school-only.
- Kept parent account creation invite-only when a parent invitation redirect is present.
- Removed the feeling of one long form by splitting the flow into Start, Identity, Security and Review steps.
- Used the Premium Simple Admin Theme direction: white background, soft card, lighter heading weights, compact spacing, consistent buttons and 16px input text for mobile.

## Scope

- Signup UI only.
- No database/schema changes.
- No feed/query changes.
- No message/composer changes.
