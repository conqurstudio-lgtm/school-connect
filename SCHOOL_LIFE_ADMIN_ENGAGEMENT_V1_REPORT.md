# School Life Admin Engagement v1

## Applied changes

- Added engagement count variables to ActivityCard
- Inserted quiet engagement pills under School Life posts
- Enriched School Life posts with reaction and question/comment counts

## Behaviour

- Admin School Life posts show quiet engagement pills only when engagement exists.
- Reactions show as `♡ reactions`.
- Parent questions/comments show as `💬 questions`.
- Future report/flag counts can show if post data includes `report_count` or `flag_count`.
- Posts with no engagement remain clean.

## Scope

- School admin Home feed only.
- No parent/teacher message changes.
- No API route changes.
- No database/schema changes.
- No private comment contents exposed.
