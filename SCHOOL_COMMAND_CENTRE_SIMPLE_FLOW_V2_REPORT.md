# School Command Centre Simple Flow v2

## Direction

The school account should only experience the school-side flow: profile, classes/teachers, and settings. Parent onboarding should sit with teachers/class spaces, not dominate the school page.

## Applied changes

- School setup: removed parent invite link from completion screen (True)
- School setup: completion now points schools to /school
- School profile page simplified to three tabs: Profile, Classes, Settings
- Parent Join tab and repeated copy-link cards removed from /school
- Classes tab now frames TeachersTab as school structure

## Untouched

- Parent Messages
- Teacher Messages
- APIs
- database/schema
- TeachersTab internals
